# Portfolio images

Place images here to make them available on the public website.

- `profile/` — your professional photo, e.g. `adzli.jpg`
- `projects/` — project screenshots, e.g. `hrms-dashboard.png`
- `experience/` — optional work or event images, e.g. `team-event.jpg`

Use optimized `.webp`, `.jpg`, or `.png` files. Keep screenshots below 1 MB where possible.

Example paths in React:

```tsx
<img src="/images/profile/adzli.jpg" alt="Muhammad Adzli" />
<img src="/images/projects/hrms-dashboard.png" alt="Workforce Management System dashboard" />
```
