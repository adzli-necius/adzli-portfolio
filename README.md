# Muhammad Adzli — Developer Portfolio

A responsive personal portfolio for Muhammad Adzli, a software developer focused on Java, Spring Boot, backend systems, and modern web applications.

## Features

- Responsive corporate technology design
- Project cards with detailed views
- Vertically scrollable experience timeline
- Writing and technical capability sections
- Frontend-only content manager
- Browser-local content persistence with localStorage
- Accessible navigation and keyboard focus states

## Technology

- React
- TypeScript
- Vite
- CSS
- ESLint

## Local development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Run lint checks:

```bash
npm run lint
```

## Content management

Open the #manage route in the browser, for example:

```text
http://localhost:5173/#manage
```

The content editor currently stores changes in the browser's localStorage. It does not use a backend or database, so saved content is local to that browser.

## Content to replace

Before publishing, replace the placeholder:
